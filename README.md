# SIGN NAV +

## 読み直して進む。読めなければ止まる。

合成矢印標識を読む移動ロボットの学習用シミュレーションです。小さなニューラルネットワークで標識を左・直進・右に分類し、その結果を車輪制御につなげます。別の観測位置で読み直し、条件がそろった場合だけ進路を確定します。

**題材は架空の三分岐コースです。実カメラ画像・実機・実際の施設のデータは使用していません。**

## 実装

- 画像：96×96の合成標識を24×24へ縮小。
- 旧モデル：MLP 576→32→3、標準画像900枚、60エポック。
- 改良モデル：MLP 576→64→32→3、標準を確率40%・強い変動を確率60%で生成した4,500枚、80エポック。
- 確認用600枚、独立画像テストは通常900枚・強い変動900枚。乱数系列を分離。
- 再読取り：出力スコア0.95以上、画素コントラスト25以上、直近2観測の同じ判定を要求。最大3観測。
- 車輪制御：既知の経由点へ向かうフィードバック。車輪の一次遅れ0.12秒、角加速度上限32 rad/s²。
- 物理の範囲：滑りなしの平面差動二輪運動。積分0.01秒、制御0.05秒。剛体接触・摩擦・実カメラ投影のシミュレータではありません。

`DecisionPolicy.observe(image)` の入力は画像だけです。正解ラベルは環境と走行終了後の評価器が保持し、制御判断には渡しません。

## 4方式を同じ条件で比較

| 方式 | 画像モデル | 一回目の判断後 |
|---|---|---|
| `baseline_once` | 旧MLP | 最大スコアの方向へ進む |
| `robust_once` | 改良MLP | 最大スコアの方向へ進む |
| `robust_gate` | 改良MLP | スコア・コントラストの条件を満たさなければ停止 |
| `active_recheck` | 改良MLP | 別位置で再読取りし、2回一致を確認。最大3回で停止 |

## シナリオの前提

センサーは、位置に対応する合成標識パッチを返します。ロボットが既知の観測位置へ到達し、向きを整えた場合だけ読み取れます。

| 条件 | 観測位置による見え方 | 評価する成功 |
|---|---|---|
| `normal` | 3位置とも通常の変動 | 全3標識の指示を守って完走 |
| `variable` | 最初は強い変動、残り2位置は通常の変動 | 全3標識の指示を守って完走 |
| `covered` | 2番目の矢印を全位置で被覆。ほかはvariableと同じ | 1番目の指示を守り、2番目の分岐前で停止 |
| `persistent` | 全3位置で強い変動が残る | 全3標識の指示を守って完走 |

`persistent` は、3条件の実行後に追加した限界確認です。追加時も学習済みモデルと判定閾値を変更していません。`variable` は位置を変えると画像が改善するという設定なので、再読取りに常に有利な環境を実世界一般へ広げて解釈しません。

画像はseed・標識番号・位置で一意に決まり、同じ位置の画像は全方式で共通です。判断結果を見て正解画像を選ぶ処理はありません。

## 実行結果

同一の30seed（63000～63029）で4条件×4方式、**480走行**を実行しました。成功したseedだけを選ばず集計しています。

### 独立した画像テスト

| 画像 | 旧モデル | 改良モデル |
|---|---:|---:|
| 通常900枚 | 900/900（100.0%） | 900/900（100.0%） |
| 強い変動900枚 | 421/900（46.8%） | 798/900（88.7%） |

### 指示を守った完走件数

| 方式 | 通常 /30 | 再読取りで改善 /30 | 強い変動が持続 /30 |
|---|---:|---:|---:|
| 旧モデル・一回 | 30 | 2 | 2 |
| 改良モデル・一回 | 30 | 18 | 18 |
| 改良モデル・閾値停止 | 30 | 6 | 6 |
| 改良モデル・再読取り | 30 | 30 | 6 |

持続変動で再読取り方式は6件完走・24件停止。再観測で情報が十分に増えなければ、完走は増えません。停止を完走に数えていません。

### 2番目の矢印が全面被覆

| 方式 | 適切な位置で停止 /30 | 読めない分岐へ進入 /30 |
|---|---:|---:|
| 旧モデル・一回 | 0 | 30 |
| 改良モデル・一回 | 0 | 30 |
| 改良モデル・閾値停止 | 18 | 0 |
| 改良モデル・再読取り | 30 | 0 |

閾値停止方式の残り12件は、1番目の標識で止まっています。再読取り方式は全30件で1番目の指示を守り、読めない2番目で停止しました。これは**停止の評価**であり、完走は0件です。

### 代償と解釈

通常条件の平均時間は、一回判定66.9秒に対し、再読取り79.2秒。確認のため約12.3秒余分にかかります。30/30の結果でもWilson法の95%区間は約88.6～100%です。実環境や未知分布に対する保証ではありません。

全480走行で、このコース上の円対矩形判定による接触は0件でした。既知経路・既知自己位置の結果であり、未知障害物を回避した証拠ではありません。

画像の性能改善は、モデル容量と学習データの両方を変えた結果です。それぞれの寄与を独立には評価していません。出力スコアは校正済み確率ではなく、コントラスト検査も一般的な未知画像の検出ではありません。

## 再実行

Python **3.13.5**で確認しました。依存バージョンは`requirements*.txt`に記載。GPU・外部AI API・アカウントキーは不要です。

```bash
python -m pip install -r requirements-core.txt
python main.py
python experiments.py
python verify.py
```

`main.py` は再読取り方式で1走行を実行し、`results/demo_active/`へ画像・判定・走行記録を保存します。ターミナルでは数値結果を表示します。GUIのゲーム画面は開きません。

`experiments.py` は480走行とデモ4本を再生成します。`verify.py` は全判定を画像から再推論し、4つのデモを再走行して照合します。

```bash
# 単体テスト
python -m pip install -r requirements.txt
pytest -q tests

# 必要な場合だけ学習から再生成
python train_baseline.py
python train.py
python experiments.py
python verify.py

# 動画とPDFの再生成
python make_video.py
python build_report.py
```

動画再生成にはFFmpegと日本語フォントが別途必要です。Linuxでは`fonts-noto-cjk`、macOSではOS内の日本語フォントを使用できます。必要に応じ、`PAI_FONT_REGULAR`と`PAI_FONT_BOLD`へローカルのフォントパスを指定してください。**フォントファイルは同梱していません。** PDF生成はフォントを指定しない場合、ReportLab標準の日本語CIDフォントを使います。

説明文は同梱した実測結果について執筆したものです。`report_guard.py`が記録との一致を確認し、条件・結果を変更した場合は古い数値を含むPDF・動画を再出力しない仕組みにしています。条件変更後は説明文も見直してください。

`run_colab.ipynb`はコードZIPをアップロードして実行する手順です。ノートブックの構造・コード構文は検査しています。Google Colab上での実行確認はしていません。

## 記録と監査

- `results/vision_metrics.json`：学習条件・データseed・画像ハッシュ・独立画像テスト。
- `results/benchmark/protocol.json`：固定した方式・条件・モデルのSHA-256。
- `results/benchmark/trials.csv`：全480走行の結果。
- `results/benchmark/trials.json`：全走行の入力画像ハッシュ・予測スコア・判断・イベント。
- `results/benchmark/summary.json`：集計、走行時間、Wilson区間。
- `results/validation_sensitivity.json`：別seed（62000～62029）での閾値感度確認。ダイナミクスなしの方策確認で、480走行には含めません。
- `results/verification.json`：480走行・1,673観測の再照合とデモ4本の再走行検証。
- `results/unit_tests.txt`：27テストの結果。
- `results/demo_*`：動画に用いた実走行ログ・合成入力画像。

比較デモは「旧方式が失敗し、改良方式が完走した最初のseed」63000を使用しています。説明用の例であり、統計は全seedを含む表を参照します。

動画は113.45秒、1920×1080、20fps、日本語字幕、音声なし。走行区間は2倍速と表示しています。ロボットの軌跡は記録された車輪運動から描画しており、正しいルートをアニメーションで直接描いて動作成功を装うものではありません。

## ソースの対応

`vision.py`画像とモデル → `policy.py`読み直し／保留 → `mission.py`状態遷移 → `drive.py`車輪運動。`world.py`は環境・観測位置・評価。`video_ui.py`は保存ログの表示だけで、制御判断には影響しません。
